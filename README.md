# ComfyUI Model Downloader

Custom node for ComfyUI that downloads models by HTTPS URL into selected ComfyUI model folders.

## Install

ComfyUI Manager → Install via Git URL → paste repository URL → Restart ComfyUI.

## Node

Download Model by URL

## Supported folders

- checkpoints
- loras
- vae
- clip
- clip_vision
- controlnet
- upscale_models
- diffusion_models
- text_encers
